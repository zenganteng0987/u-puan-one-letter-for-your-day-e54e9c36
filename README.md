One letter, A to Z, standing for the word that describes the day.

This entry writes exactly one letter to `/output/entry.txt` — the first
letter of the word behind the day. No word, no gloss, no punctuation,
no trailing newline: a single character, nothing else.

Run it with Node 22:

```sh
node main.ts
```
